Why this route

Three options were weighed after the team agreed calls must be automatic and WhatsApp is only for messages.

Dropped

Calling through WhatsApp Web

A web page cannot drive web.whatsapp.com and personal WhatsApp has no calling API. Every call needed a person to send, dial and confirm, and it can never run in parallel.

Chosen for the prototype

Android phone as the line

Reuses the existing agent page (answer detection, transcript, recording, Kontrak B1). Real Indonesian number, cost is phone credit. ADB dials with no tap. One phone = one line.

Production, later

BPJS SIP line + Asterisk

For production, BPJS's own SIP trunk (e.g. Care Center 165) behind Asterisk keeps an official number and data in Indonesia. The phone line sits behind one small helper, so that swap touches one component.

    Phased plan

    Each phase leaves the system working. Phase 0 is a gate on the real phone; Phases 1–4 can be built and tested without it using the fake phone helper. The first acceptance run is local (dev.sh on the station laptop). Ticks are saved in this browser only.

    Day-one feasibility check

    About 30–60 minutes with the actual phone, cable and a tester's phone. Every row must pass before Phase 1 starts.

    If any of steps 1–5 fails: for audio, switch between speakerphone and the cable kit; for dialing, set a default SIM and try a second phone model (stock Android with a 3.5 mm jack). Only the Phone helper and the station hardware depend on the phone.

    Line station hardware

    Set up once by the team, then left running. The officer never touches it. Start with speakerphone (phone on speaker beside the laptop, no cables, Chrome echo cancellation on). Add the cable kit below only if transcripts are poor.

    Rules that do not change

    • Labels and the RS summary are computed only by the backend with data-uji-konfirmasi/tools/aturan.py. The station and the reader never send a label.
    • Two attempts maximum, retry delay and WA delay decided by the server clock; fallback chat after the second miss.
    • Call script R3.3: admits it's an automated assistant; never asks for NIK, OTP, bank details or money; never says “curang” or “fraud”. WA text = Lampiran B, no links.
    • A person decides. “Pilih tindakan lain” always needs a written reason.
    • Recipient identity never reaches hospitals. Screens stay labelled “Simulasi”. No BPJS logo. Synthetic data only; prototype calls go to tester numbers (NOMOR_PENGUJI).
    • Secrets (GEMINI_API_KEY, AGEN_KEY, Meta token) stay server-side or in the station's local env, never in the officer's browser or in git.
    • The simulation fallback (data-v3.js) and the stubs keep working when the API or station is down.
